    ## useClickOutside

    Custom hook that detects clicks outside a specified element and triggers a callback function. This is useful for handling dropdowns, modals, or tooltips that should close when clicking outside of them.

    ### Parameters

    - **`callback`** : A function that gets triggered when a click is detected outside the target element.
    - **`relativeElements`** (optional): An array of `RefObject<HTMLElement>`, which are elements that should not trigger the callback when clicked.

    ### Returns

    - A ref callback function that should be assigned to the element whose outside clicks you want to detect.

    ### Usage

    ```tsx
    import React, { useRef, useState } from 'react';
    import { useClickOutside } from '@geneui/components';

    const MyComponent = () => {
        const [isOpen, setIsOpen] = useState(false);
        const relativeRef = useRef(null);

        const handleClickOutside = () => {
            setIsOpen(false);
        };

        const ref = useClickOutside(handleClickOutside, [relativeRef]);

        return (
                <div>
                    <button onClick={() => setIsOpen(!isOpen)}>Toggle Menu</button>
                    {isOpen && (
                        <div ref={ref} style={{ border: '1px solid black', padding: '10px' }}>
                            This is a dropdown
                        </div>
                    )}
                    <span ref={relativeRef}>Relative Element</span>
                </div>
                )};

    export default MyComponent;
    ```
