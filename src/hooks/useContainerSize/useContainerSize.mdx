## useContainerSize

This hook provides the current width and height of a container element and updates dynamically when the container resizes using `ResizeObserver`. You can optionally debounce resize notifications using `useDebounceCallback` to avoid excessive renders during rapid window/container resizing.

#### Returns

An object containing:
-   **`containerRef`**: A ref object that should be attached to the element you want to measure.
-   **`sizes`**: An object with `width` and `height` properties representing the container dimensions in pixels.

#### Parameters

-   **`observeResize`** (optional): Whether to observe resize changes. Defaults to `true`.
-   **`debounceWait`** (optional): Debounce delay in milliseconds for resize updates. If `0` or omitted, updates are applied immediately (no debounce).

#### Usage

```js
import React, { FC } from 'react';
import { useContainerSize } from '@geneui/components';

const ExampleComponent: FC = () => {
    const { containerRef, sizes } = useContainerSize();

    return (
        <div ref={containerRef}>
            <p>Container Width: {sizes.width}px</p>
            <p>Container Height: {sizes.height}px</p>
        </div>
    );
};

export default ExampleComponent;
```

#### Advanced Usage

```js
import React, { FC } from 'react';
import { useContainerSize } from '@geneui/components';

const ExampleComponent: FC = () => {
    // Disable resize observation for better performance
    const { containerRef, sizes } = useContainerSize({ observeResize: false });

    return (
        <div ref={containerRef}>
            <p>Container Width: {sizes.width}px</p>
            <p>Container Height: {sizes.height}px</p>
        </div>
    );
};

export default ExampleComponent;
```

#### Responsive layout example

```tsx
import React, { FC } from "react";
import { useContainerSize } from "@geneui/components";

const ResponsiveBreadcrumbWrapper: FC = ({ children }) => {
    const { containerRef, sizes } = useContainerSize({ debounceWait: 100 });

    // You can pass sizes.width down to a child (for example, Breadcrumb)
    // and compute how many items fit in that width.
    return (
        <div ref={containerRef}>
            {React.cloneElement(children as React.ReactElement, {
                containerWidth: sizes.width
            })}
        </div>
    );
};
```

#### Notes

- This hook uses the `ResizeObserver` API and can debounce updates (via `debounceWait`) to reduce render thrash while dragging resizers.
- It performs an **initial synchronous measurement** on mount, so you immediately get the real container size before any debounced updates.
- The `ResizeObserver` is automatically cleaned up when the component unmounts to prevent memory leaks.
- If `observeResize` is set to `false`, the hook will only measure the initial size and won't track changes.
- The hook returns a ref that must be attached to the element you want to measure.
